# 菜品专属示意图

本批图像使用内置 imagegen 逐道生成，用于多来源检索后仍未取得可复用成品照片的地方菜。它们描绘具体菜式的典型食材与做法，不是餐厅或商家的实拍，不代表某家餐馆的份量、摆盘、售价或品质。菜品会有地方与店家差异，以实际菜单为准。

网页的图片详情、作者栏和替代文本保留“AI 菜品示意图”说明；目录统计将这些图像与实拍分开。随后找到准确实拍时，维护程序优先替换为实拍。

2026-09-23 本批完成后，713 项特色食物均有本地配图：653 项使用实拍，60 项使用菜品专属插画，通用食物插画为 0。实际统计以 `data/catalog-coverage.json` 的 `foodCoverage` 为准。

- 发布文件：`public/images/art-food-*-20260923.webp`。
- 每张图的完整提示词、对应菜品 ID、生成方式和署名：[`data/food-art-expansion`](../data/food-art-expansion/)。每道菜独立生成，没有把通用餐桌图重复分配给不同菜式。
- 工具：内置 imagegen，2026-09-23。没有使用 API/CLI 生图。
- 原始生成文件保留在本机生成目录；网页版本仅按比例缩小并编码为 WebP，没有修改菜品内容或拼接别的图片。
- 导入工具：`scripts/import-generated-food-art.py`，仅负责已有图片的网页编码与元数据写入，手动使用时需要 Pillow。自动部署使用仓库中已保存的 WebP，不调用生图或 Pillow。

这些是项目生成素材，不借用商家摄影的授权标签，也不声称真实现场拍摄。
