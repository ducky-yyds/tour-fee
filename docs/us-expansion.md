# 美国目的地扩展

2026-09-23 批次在纽约、洛杉矶之外增加 24 座详细目的地。城市文件分为 `data/expansion/us-east.json`、`us-west.json`、`us-inland.json`；住宿在对应的 `data/experience-expansion/` 文件中，食物在 `data/food-expansion/` 中独立维护。

| 目的地组 | 新增城市 |
|---|---|
| 东岸与历史文化 | 华盛顿特区、波士顿、费城、芝加哥、亚特兰大、查尔斯顿、萨凡纳、迈阿密 |
| 西部与海岸 | 旧金山、西雅图、圣迭戈、拉斯维加斯、波特兰（俄勒冈州）、蒙特雷、檀香山、安克雷奇 |
| 音乐、美食与内陆门户 | 奥兰多、新奥尔良、纳什维尔、奥斯汀、圣安东尼奥、丹佛、盐湖城、弗拉格斯塔夫 |

此次新增 332 个景点与体验、120 种特色食物和 120 家具名住宿，美国详细目的地由 2 座增至 26 座。每城提供主要地标、街区、免费漫步及可自选体验，并至少收录五种特色食物和五家具名住宿。华盛顿特区不归为华盛顿州，檀香山的城市行程限于瓦胡岛；大峡谷、落基山等远郊项目与主题乐园保留整日候选，不作为短时市内补空项目。建议停留天数是编辑建议，跨城交通仍会占用行程时间。

日常支出、长租和住宿选项为明确标注的编辑预算；新增住宿的三档选项是城市预算预留，不代表该酒店有对应价位或房型。官方旅游、场馆、酒店网页用于核对地点与访问内容，不能把网页可访问误当成某天有房或门票已预订。各包的具体资料见 [东部来源](us-east-sources.md)、[西部来源](us-west-sources.md)、[内陆来源](us-inland-sources.md)。

2026 年部分国家公园对非美国居民有额外入场费用。按车、按人、年票及商业团的计费口径不同，本应用目前的普通景点预算以每位成人为单位；无法准确表达组合收费时保留费用待核状态，不能直接将每车费用填成每人门票。核对来源：[NPS 非居民费用](https://www.nps.gov/aboutus/nonresident-fees.htm)、[大峡谷费用与通行证](https://www.nps.gov/grca/planyourvisit/fees.htm)、[落基山费用与通行证](https://www.nps.gov/romo/planyourvisit/fees.htm)。

`npm run import:destinations` 同步导入城市、指南和独立食品包；`scripts/build-food-catalog.mjs` 也会读取食品包并保留已有人工修正。机场通过已核对的机场代码、州别和距离关联，详情见 [机场维护](airports.md)。图片沿用 [图片维护流程](images.md)，逐张记录来源与许可，实际图片覆盖以目录审计为准。
