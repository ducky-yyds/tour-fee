# 本轮产品取舍

2026-09-22 查看 [Nomads.com](https://nomads.com/) 的公开页面：它将城市发现、搜索筛选、费用指标、对比和旅行记录放在较近的入口。本轮借鉴可浏览、可比较、可反复调整的组织方式，没有复制其页面或将其估算当作本应用的实时报价。

途算保留自己的纸色、绿色、华文中宋与 Georgia 字体体系，以具体旅行项目为中心：城市卡片支持按日常成本排序；项目卡片展示日期、人数和全程预算；费用页把日常偏好与单次费用分开；每天按照片、时间线和可调游览节奏展开。

修复“一天 33 小时”分两种情形：自动安排受时间容量约束，候选项不自动全部加入；手动安排保留用户选择，并对过满、绕路、闭馆或缺少交通坐标提示。天数缩短时重新精选，未排入的地点仍可在候选清单和景点库找到。

没有把城市景点库的完整程度与自动行程长度绑定。更多收录意味着用户有更多可选项，而不是每次生成更多站点。当前 30 城 262 景点的范围明确可见，目录之外可以添加项目专属地点。

旅行项目保存在本地浏览器，旧当前行程与收藏首次迁移为独立项目；项目复制使用独立计划文档，切换项目重建日程编辑器，避免把另一项目的撤回记录带入当前项目。
