# 冰岛、马尔代夫与补充目的地

2026-09-22核对官方旅游介绍。票价除单列Green Tax外全部是未核验的人工规划范围；坐标为规划参考，不能代替导航。马富施私岛准入未确认的地点保留候选，不自动推荐。

- 雷克雅未克：10处；[官方目的地资料](https://visitreykjavik.is/sights-attractions)。市区可步行及公交；黄金圈、蓝湖等城外目的地需另订接驳、自驾或跟团。冬季日照与路况会改变可行行程。
- 维克与冰岛南岸：8处；[官方目的地资料](https://www.south.is/en/destinations/travel-routes/the-south-coast)。景点分散，采用公路行程估算；需自驾、包车或已确认巴士团。凯夫拉维克为国际门户，不是维克镇机场。冰川和冬季道路不可只按直线距离安排。
- 阿克雷里：8处；[官方目的地资料](https://www.visitakureyri.is/en/see-and-do/attractions)。镇内步行；米湖、地热区和众神瀑布建议自驾或公路团，冬季受路况和日照限制。
- 马累与周边岛屿：8处；[官方目的地资料](https://old.visitmaldives.com/male-city/)。旅游预算以USD表达；本地同时使用MVR。跨岛需核对快艇/渡轮班次与天气，度假村接送可能需额外购买水飞或专船。居民岛住宿与度假村不可视作同一种产品。
- 马富施岛：5处；[官方目的地资料](https://maafushi.gov.mv/guide)。机场位于马累附近，往返马富施必须另外安排船班。跨岛均按待核船程显示；交通预算覆盖日常船程预留，私人度假岛准入和包船费用须独立核价。
- 爱丁堡：8处；[官方目的地资料](https://www.visitscotland.com/places-to-go/edinburgh/things-to-do)。时间与路程按地理模型估算；实际公共交通时刻、营业安排和预约余位需确认。
- 都柏林：8处；[官方目的地资料](https://www.visitdublin.com/things-to-do)。时间与路程按地理模型估算；实际公共交通时刻、营业安排和预约余位需确认。
- 布鲁塞尔：8处；[官方目的地资料](https://www.visit.brussels/en/visitors/what-to-do/attractions-and-monuments.BME.251039)。时间与路程按地理模型估算；实际公共交通时刻、营业安排和预约余位需确认。
- 杜布罗夫尼克：8处；[官方目的地资料](https://tzdubrovnik.hr/lang/en/news/spomenici/index.html)。时间与路程按地理模型估算；实际公共交通时刻、营业安排和预约余位需确认。
- 卡帕多西亚·格雷梅：8处；[官方目的地资料](https://goturkiye.com/cappadocia/routes)。NAV为门户机场之一，也可查ASR；目的地是格雷梅周边区域。地形有坡度，跨谷与地下城按公路估算；热气球须另订运营方并受天气影响。

[马尔代夫Green Tax法规](https://www.mira.gov.mv/Legislations/View/Green-tax-regulation)：成人6或12 USD按住宿类型分别计收，本应用按夜数做预留，并非税务账单。
