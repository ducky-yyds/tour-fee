所有新增目的地有城市主页、饮食特色、街区导览、推荐游览时长、坐标、日常与月居三档预算、官方旅游/场馆资料链接。景点可以选择加入项目并智能分配，用户仍可调整顺序与时长。

本批官方来源用于确认地点、特色与访问条件。**559 条新增景点预算均为未逐一核验的编辑估算**，`price.type=estimate`、`checkedAt=null`；0 元也不等于已经核实免费。住宿、饮食、租金都是规划范围，不是即时库存报价。新增城市未核实餐厅、酒店与供应商的分类保留明确空态；现有 30 城的 90 个具体商家/项目不冒充全球覆盖。

45 个显示币种已接入 Frankfurter 更新。`data/fx-reference.json` 为本轮真实获取的参考快照，保留日期和来源；旧数据库缺少新币种时使用参考快照并标注缓存，避免默认按 1:1 换算。

交通按地图坐标模型估算，不查询实时路况和时刻表。标记的离岛船程与公路段会单独展示时间及日交通预算分摊。马累至马富施按船程预算；国外至马富施查询 MLE 国际门户，另预留机场至岛屿接驳。冰岛本批目的地间按公路预算，日照、路况、租车或巴士可行性需要另核。

马尔代夫 Green Tax 依据 [MIRA 法规](https://www.mira.gov.mv/Legislations/View/Green-tax-regulation)按成人夜数预留 6–12 USD，实际按住宿类型与法定计费时段核算；已含税报价可将这一行改为 0。私人度假岛的准入未确认时不会自动排入，手动加入会提示。

吴哥、会安的通票组同日去重，跨日分别预留；城市选择篮用可能共用至分日使用的范围展示，生成后按实际分日核算。所标记夜市的建议时段不早于 17:00，建议不是官方营业承诺。

图片来自 Wikimedia Commons，保留逐张署名、许可和来源。本批采集会过滤旗帜、Logo、地图和未识别许可。无法核实的景点保持明确“城市参考图”占位，不冒充景点照片。当前实际覆盖、缺失清单由 `npm.cmd run audit:catalog` 输出至 `data/catalog-coverage.json`。

本轮验证完成：81 项程序测试、19 项桌面/手机浏览器检查、100 城共 200 组一日/三日智能规划检查通过；100 张主图与 819 张景点实景已下载，另外两处保留明确占位。数据校验、浏览器截图与图片解码结果均在 `artifacts/qa/`。网络连续失败会保存进度并终止本轮采集，之后重跑可恢复。

维护步骤：修改 `data/expansion/` 的分区 JSON → `npm.cmd run import:destinations` → `npm.cmd run audit:catalog` → `npm.cmd run update:images`（本机可加 `--python-network`）→ 核查图片 → `npm.cmd test` 与构建。导入只同步扩展目录中的城市，不删除原城市、项目或用户数据。
