# 跨城交通与日程

费用与时间共同读取每段的交通方式，预算明细和每日时间轴保持一致：

- `leg-0` 等计入去程与每次换城；`leg-return` 在启用返程时计入。票价按成人数量乘单程预算；`transfer-*` 另列两端车站或机场接驳，公路与渡船的接送在其预算范围内，不重复加机场接驳。
- 门票与交通之间没有重复加总：时间轴引用费用明细中的原条目，跨多日的同一段交通仅在首次出现时列其金额。
- 时间预留先进入每日可活动窗口，然后智能精选再考虑游览、用餐、市内交通。当天没有合适窗口时保留交通日，未排景点留在候选中。
- 新的自动计划用 `planningMode: "smart"` 标记；手动调整用 `manual`。旧存档按手动保留，出现冲突后可主动智能重排。

## 默认占时模型

模型仅用于分配旅行日，未查询用户出行日期的班次、余票或实时票价。铁路可达范围是逐组维护的城市名单，不能仅凭“同一国家”或距离近推断有铁路；具体车站、换乘、夜间运行和时区仍需查运营方。

“智能选择”在维护的铁路连接中优先选择门到门预留不超过 7.5 小时的高铁/动车，或不超过 6 小时的常规铁路，较长距离默认航空；用户可显式选择已支持的其他方式。京沪采用高铁默认值；京广可切换到高铁。海南仅维护岛内动车，不提供大陆直通纯高铁；札幌仅提供包含新干线及在来线的混合铁路预算，不显示新干线直达。

| 场景 | 初始分钟估算 |
|---|---|
| 马尔代夫 150 km 内跨岛 | 距离 × 1.2 ÷ 25 km/h × 60 + 90 分钟 |
| 冰岛 450 km 内公路 | 距离 × 1.35 ÷ 50 km/h × 60 + 60 分钟 |
| 已维护高铁 / 动车 | 路线参考里程 ÷ 本地区平均运行速度，加候车及两端车站接驳；主要城市对采用取整行程参考 |
| 已维护普通铁路 | 独立的常规铁路速度、票价系数及必要换乘预留，不沿用高铁速度 |
| 其他航空预算 | 距离 ÷ 700 km/h × 60 + 国内 180 / 跨国 240 分钟；目的地需额外门户转运时再加 90 分钟 |

最低 60 分钟，向上取整到 15 分钟。具体网络、城市名单、里程锚点、时间与费用系数见 `shared/rail-network.mjs`。所有系数和取整值都是编辑规划假设，不是运营方票价表；三档金额是预算范围，也不保证每趟车提供三种对应席别。铁路费用按当地币种估算，再由统一汇率转换；接驳另外列账。

每天默认用 09:00–20:30 的 690 分钟容量容纳跨城预留，长途分配至多个日期；入城占本站开头，返程从最后一站末尾向前分配。普通本地活动还受“480 分钟减去交通预留”的负荷上限约束。长途交通本身可超过 8 小时，此时不再追加游览。无法容纳入返程时明确提示延长旅行，不伪造可用时间。

## 有车票或机票后

在预算栏的城际交通明细中选择交通方式，并展开时间细节填写目的地当地的活动边界：

1. 抵达后可开始活动的时间，应已包含入境、取行李和前往市区。
2. 跨夜抵达选择本站第几天才可活动。
3. 返程日最晚结束游览时间，应在该时刻离开景点并留足去机场/车站、值机等时间。

这些字段保存于各旅行项目的 `stop.transportWindow`，与足迹、长期生活偏好相互独立。切换交通方式后，受影响航段的旧活动边界撤下，重新按新方式预留时间；自动计划重排，手动计划保留并报告冲突。具体餐厅/套餐如不能排入，仍保留用户的选择与费用并提示待安排。

酒店夜数仍按旅行项目的“总天数减一”预算，尚未根据真实夜航/火车卧铺自动扣除住宿；录入实际住宿报价时需按真实入住夜数核对。旧旅居模式按完整住宿夜数处理，返程次日费用列于总预算。

## 保存和报价兼容

```js
{
  transportModelVersion: 2,
  transportModes: {
    'leg-0': { fromId: 'beijing', toId: 'shanghai', mode: 'high-speed-rail' },
    'leg-return': { fromId: 'shanghai', toId: 'beijing', mode: 'air' }
  }
}
```

支持 `auto`、`air`、`high-speed-rail`、`rail`、`road`、`boat`；自动模式可不保存。每条选择绑定起终点，更换城市后不会把原选择错用于另一段。仅有机场信息而未维护铁路连接的城市不会自动获得铁路选项。国家规划继承既有段的方式，新增城市导致返程起点改变时，旧返程选择自然失效。

`migrateJourneyTransport` 保留旧存档已录入交通金额的原语义：此前大陆预算实际上是航空模型，因此有用户交通金额记录的旧段显式保留飞机；未录入的旧段使用新的自动选择。旧岛屿公路、渡船与岛内铁路按原类型保留。不批量清除用户报价。

`preserveUnchangedQuotes` 在比较前先处理旧模式，再只保留完整参考条目未改变的金额。条目包含交通方式、起终点和旅行日期：飞机改高铁时，旧机票和机场接驳记录不会成为高铁报价；同一方式、路线和日期未改变的记录继续保留。

- 日本：[JNTO 新干线网络](https://www.japan.travel/en/plan/getting-around/shinkansen/)、[札幌交通指南](https://www.sapporo.travel/en/info/about/transportation/)。台湾地区：[高铁](https://en.thsrc.com.tw/)、[台铁](https://www.railway.gov.tw/tra-tip-web/tip?lang=EN_US)；韩国：[KORAIL](https://www.korail.com/)。
- 欧洲：[Eurail 路网](https://www.eurail.com/content/dam/pdfs/Eurail-Map-2025.pdf)、[SNCF 目的地](https://www.sncf-connect.com/en-en/train)、[Renfe](https://www.renfe.com/es/en)、[CP 里斯本—波尔图时刻资料](https://www.cp.pt/info/documents/d/cp/comboios-alfa-pendular-intercidades-lisboa-norte-sul)、[Trenitalia](https://www.trenitalia.com/en.html)、[National Rail](https://www.nationalrail.co.uk/)、[SBB](https://www.sbb.ch/en)、[Eurostar 目的地](https://www.eurostar.com/rw-en/destinations)。只开放代码中明确维护的城市组，不把欧洲所有城市当作同一连通组。
- 美国：[Amtrak 运营路线](https://www.amtrak.com/train-routes)，维护东北走廊、Seattle—Portland 和 Los Angeles—San Diego；Acela 使用独立于中国高铁的运行速度与美元预算。
