本批新增32个中国内地目的地和澳门，数据以本地源包、SQLite运行数据库与原始资产归档为主；GitHub Pages只发布预览产物。

| 华东及南部 | 黄山、合肥、福州、武夷山、景德镇、扬州、绍兴、潮州、澳门、乐山、贵阳 |

三组源包共650个景点、175项独特体验、165种食物和165家具体住宿。每个新增目的地有25项景点与体验、5种食物和5家住宿。已有城市另增16项体验，包括川菜烹饪、林木物候、观鸟、扎染、昆曲、冲浪和帆船。

## 数据与价格边界

- 内容来源、阅读日期与核验范围保留在`sourceReferences`。地方旅游资料用于说明地点与文化背景，不能据此声称核实了某家商户的当日菜单、房态或报价。
- 大部分金额为编辑预算区间，`type: estimate`，不冒充市场最低/最高或实时价格。实际核对到的官方票价才标`official`。门票、餐饮、住宿按各自单位计价。
- 远郊有单程交通预留和接驳说明；未经确认的准入、节庆、课程与季节活动不按每天可参加处理。长距离活动不自动与市内小景点拼在半天。
- 明确替代正餐的体验使用`includedMeals`抵扣普通餐饮预算；饮茶、小吃试吃和未注明含餐的手作不抵扣正餐。
- 拉萨、林芝抵达后的首个可活动日设置240分钟活动量上限，包含用餐和市内交通，优先休息与短途活动。这是规划节奏约束，不是医学安全判断。手动选择超额时保留用户内容并提示调整。
- 跨夜铁路连续推进并在午夜拆分，不再每天从09:00重新计算；旅行模式扣除在途夜的目的地住宿，入住日期、默认住宿和所选酒店使用同一组有效夜数。返程预订日期采用交通实际开始日。旅居月租仍保留完整租期，手动费用记录保持优先。
- 平遥古城联票以首次实际使用日开始计算3个自然日，有效期内各包含点只计一次购票费用；再次入场规则、未包含景区与演出须另外核对。来源：[平遥古城官方票务说明](https://www.pygc.com/single/13)。
- 澳门使用MOP。已从[Frankfurter完整币种接口](https://api.frankfurter.dev/v2/rates?base=CNY)取得并校验2026-10-07参考汇率，47种币种（含人民币基准）已写入SQLite及参考快照，1 CNY = 1.2073 MOP。参考中间汇率不含实际兑换手续费或买卖价差。

## 照片与归档

照片映射独立保存在`data/{place,experience,food,hotel}-photo-expansion/`，候选检索与审核结果分开。检索命中不是核验通过；逐页联系表用于排除异地同名、地图、人物肖像、错误菜品和过时现场。`exact-place`表示对应地点，`nearby`或`related-theme`明确写出图片的实际地点及示意范围，不能把异地图片当酒店物业实拍。

33个城市封面已下载并目检。白沙古镇原误用云南位置图，已换成古镇街巷照片；南京纪念馆检索误命中合肥、重庆杨森公馆误命中武汉等候选均拒绝导入。新图片保存作者、文件名、许可和源地址。无法取得对应真实照片的条目保留缺口，不改成“已核验实拍”。

本批新增条目的实际照片覆盖如下（按卡片计数，包括明确标注范围的主题照片，不等同于独立图片数量）：

| 类型 | 总条目 | 已有照片 | 待补实拍 |
| --- | ---: | ---: | ---: |
| 景点 | 650 | 318 | 332 |
| 独特体验 | 175 | 60 | 115 |
| 特色食物 | 165 | 77 | 88 |
| 住宿 | 165 | 15 | 150 |

逐城市缺口保存在`data/china-expansion-audit.json`，不能把内容数量达标表述为照片全部补齐。连同33张城市封面和既有条目修复，本轮引用495个本地图片文件，均已取得源站原始文件并保存在私有资产归档；过去批次仍有原图缺口，清单分别记录。

本地图片原始字节由`npm run archive:assets`归档，正式部署文件、数据库和原始资产对象由`npm run archive:snapshot`存储。源站原图下载失败时，归档清单区分已保存的前端版本与原始文件缺口，不把缩略图当无损原图。

Pages构建仅在`dist-pages/images`内压缩发布副本，为1GB预览站上限留空间；不修改`public/images`、本地原图归档或生产构建。原始数据及正式部署资产不受预览站大小限制。
