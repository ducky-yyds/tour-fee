# 美洲与非洲逐城体验补充 · 2026-09-23

覆盖现有美洲 36 城、非洲 10 城；每城新增三项有具体文化或自然主题的体验。所有价格均为编辑估算，不是实时可订价格；公共免费活动也保留核对入口。

研究以旅游局、国家公园、PADI、文化机构及经营者资料为主。节庆月份是常见窗口，不代表今年已确认日期。观鲸、海豚、海牛等均不保证遇见；不加入触摸、投喂、追逐野生动物的项目。

跨城或远郊活动在介绍中说明接驳，includesTransfers 均为 false，避免把接送费默认为已含。未找到可确认主体与使用来源的照片时不写虚假的 photoFile，也不把城市背景当作该活动实拍。
